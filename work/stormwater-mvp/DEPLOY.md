# Деплой Stormwater

## Онлайн 24/7

Проект подготовлен как статический сайт и может работать на Netlify, Vercel, GitHub Pages или любом CDN.

Для Netlify уже добавлен `netlify.toml` с каталогом публикации `work/stormwater-mvp`. Нужно подключить репозиторий в Netlify и нажать Deploy. После этого Netlify будет держать сайт доступным 24/7 и выдаст HTTPS-домен.

Важно: текущий MVP хранит заявки только в памяти браузера. Для настоящего публичного сервиса нужно подключить backend/database, чтобы жалобы не терялись между пользователями.

## Локальный 24/7-процесс

```powershell
Set-ExecutionPolicy -Scope Process Bypass
./start-server.ps1 -Port 4173
```

Локальный сервер будет работать, пока запущен PowerShell-процесс. Для постоянного онлайн-доступа нужен внешний хостинг или сервер с доменом.
