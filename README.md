# Stormwater ASTANA OPS

Операционный MVP для управления рисками подтоплений и ливневой инфраструктурой.

## Что демонстрирует MVP

- карта объектов и паспорт инфраструктуры;
- прогноз осадков Open-Meteo и оценка риска;
- жалоба жителя с фото и геолокацией;
- маршрутизация заявки бригаде и SLA;
- фотоотчёт и подтверждение результата;
- история событий, импорт GeoJSON/CSV и экспорт отчёта.

## Запуск

```bash
npm run build
python -m http.server 4174 --directory dist
```

Это демонстрационный frontend-MVP: обращения хранятся в браузере. Для пилота подключаются API диспетчерской, PostgreSQL/PostGIS и хранилище фотографий.
